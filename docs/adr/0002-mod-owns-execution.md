# The mod owns execution; Claude only advises

The mission loop (Craft Check → timing → plan → Approval → execute → Debrief → next plan) is a state machine in the mod, which calls Claude at defined points with tools to read state and propose plans; Claude can never start a kOS script itself, and only the mod does so, after the player's Approval. We chose this over a free-running agent loop with an "execute" tool so that Approval is a hard guarantee rather than a prompt instruction, and so the Mission's state is explicit, inspectable and persistable.

**Amendment (Blackout):** during a Blackout, the player's Approval of the Mission Plan stands in for each Maneuver Sequence's Approval. Claudia may fly the planned sequences and may revise the Mission Plan herself within the Mission Goal and the Spending Cap; the player sees each revision, with her reasons, when the link returns. A Failed Debrief waits for the link. The mod still starts every script; Claude still only advises.

As built (#62): the Approval that stands is one the player actually gave. The first Mission Plan is never taken in a Blackout, and a manual stretch or a Sequence Plan with a Due Time waits for the player (even once the Due Time is reached), since both need them by definition (ADR 0004). The link fact is unknown after a load until the craft is seen again, so nothing that waits for the link goes ahead on a guess. The revisions list, the player's held words and her queued messages are kept in memory only: a load during a Blackout loses the list and the held words, and shows her queued messages. Every script still passes the Script Check first, Custom Scripts included, and one that fails twice waits for the link at "Couldn't produce a safe script". In a Blackout no request Pauses at the Spending Cap: it becomes the waiting call, because the player couldn't answer a Pause. A Failed Debrief always makes the craft safe; in a Blackout it neither ends the Mission nor offers a reduced goal until the link is back. Link loss in Manual Control with nobody else aboard follows the same rules: Claudia takes the craft back, makes it safe, Debriefs the stretch and flies the revised Mission Plan.
