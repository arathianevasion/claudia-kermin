Auto Mode switch prototype

A throwaway mock of the Capcom strip, the Mission window and the Settings window, in the mod's own colours, with three placements for the Auto Mode switch. Use the pill at the bottom (or ← →) to change variant. Use the purple buttons to send Claudia's next move and see how each variant reacts.
